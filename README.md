# forge-veil.github.io

[![Deploy](https://github.com/forge-veil/forge-veil.github.io/actions/workflows/deploy.yml/badge.svg)](https://github.com/forge-veil/forge-veil.github.io/actions/workflows/deploy.yml)

Personal site and writing by [Vatsal Bakshi](https://forge-veil.github.io). Built with Astro 6, Three.js, and KaTeX.

## Development

```sh
npm install
npm run dev
make build
```

## Deploy

Push to `main` triggers tests, PDF compilation, and deployment to GitHub Pages.
